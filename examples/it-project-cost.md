## COST OPTIMIZATION OPTIONS

### Option A: Right-size Workstations (Recommended)

Current spec is over-powered for office productivity tasks. Downgrade to business-class desktops:

| Change | Current | Optimized | Savings |
|---|---|---|---|
| Desktop PC | Rp 12.5jt each | Rp 8.5jt each (i5, 16GB, 512GB SSD) | Rp 120.000.000 |
| Docking station | Rp 1.85jt each | Rp 1.25jt each (USB-C basic) | Rp 18.000.000 |
| Monitor | Rp 2.1jt each | Rp 1.65jt each (22" vs 24") | Rp 13.500.000 |
| **Subtotal savings** | | | **Rp 151.500.000** |

**Revised workstation cost: Rp 366.550.000**

### Option B: Cloud-First Approach

Replace on-premise servers with cloud services:

| Component | On-Premise | Cloud | Savings |
|---|---|---|---|
| File server | Rp 32jt | Google Workspace/OneDrive | Rp 32jt |
| App server | Rp 38.5jt | Cloud VM (AWS/Azure) | Rp 20jt/yr |
| NAS backup | Rp 15.5jt | Cloud backup service | Rp 8jt/yr |
| Server room AC | Rp 12jt | N/A | Rp 12jt |
| **Net savings (3yr)** | | | **Rp 40–50jt** |

**Trade-off:** Ongoing cloud costs ~Rp 8–12jt/month vs one-time hardware.

### Option C: Phased Implementation

Split into two phases:

**Phase 1 (Month 1–2): Critical infrastructure**
- Network core + access
- File server + backup
- 15 workstations (priority users)
- Basic software
- **Cost: ~Rp 800jt**

**Phase 2 (Month 3–4): Full deployment**
- Remaining 15 workstations
- Application server
- Full software suite
- Advanced services
- **Cost: ~Rp 700jt**

**Benefit:** Spread cash flow; validate Phase 1 before committing Phase 2.

## ASSUMPTIONS

```
ASSUMPTION: 30 users, standard office productivity workloads
ASSUMPTION: No specialized software (CAD, video editing, etc.)
ASSUMPTION: Existing internet connectivity sufficient (100Mbps+)
ASSUMPTION: Server room space allocated (min 4m²)
ASSUMPTION: UPS backup for 30 minutes minimum
ASSUMPTION: 3-year hardware warranty, 1-year software license
ASSUMPTION: All prices ESTIMATED — no live vendor quotes
ASSUMPTION: PPN 11% on hardware; software may have different treatment
ASSUMPTION: Installation by certified technicians
ASSUMPTION: 6-week timeline achievable with standard lead times
```

---

## EXCLUSIONS

```
- Specialized software (industry-specific, CAD, etc.)
- Data migration from existing systems
- Legacy system integration
- Cybersecurity beyond basic firewall + antivirus
- 24/7 monitoring or managed IT services
- Hardware refresh cycle (assumed 3-5 years)
- Mobile device management (MDM)
- Cloud infrastructure costs beyond initial setup
- Staff IT support beyond go-live period
```
