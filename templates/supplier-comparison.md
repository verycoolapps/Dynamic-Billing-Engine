## SCORING RUBRIC DETAIL

### Price Competitiveness (25%)

| Score | Criteria |
|---|---|
| 5 | Lowest price AND verified |
| 4 | Below median price |
| 3 | At median price |
| 2 | Above median but within 20% |
| 1 | Above median by 20–40% |
| 0 | Above median by >40% or price unverifiable |

### Spec Match (25%)

| Score | Criteria |
|---|---|
| 5 | Exact spec match, all requirements met |
| 4 | Equivalent spec, minor differences acceptable |
| 3 | Mostly matches, minor gaps |
| 2 | Partial match, notable gaps |
| 1 | Inferior spec or missing scope |
| 0 | Does not meet requirements |

### Delivery/Lead Time (15%)

| Score | Criteria |
|---|---|
| 5 | Can deliver well before deadline |
| 4 | Can deliver by deadline |
| 3 | Tight but feasible |
| 2 | May be late |
| 1 | Likely late |
| 0 | Cannot meet deadline |

### MOQ Flexibility (10%)

| Score | Criteria |
|---|---|
| 5 | No MOQ or MOQ below needed qty |
| 4 | MOQ equals needed qty |
| 3 | MOQ slightly above needed (10–20%) |
| 2 | MOQ 20–50% above needed |
| 1 | MOQ >50% above needed |
| 0 | MOQ prohibitive |

### Warranty & Terms (10%)

| Score | Criteria |
|---|---|
| 5 | Long warranty, clear terms, favorable conditions |
| 4 | Standard warranty, clear terms |
| 3 | Basic warranty, terms acceptable |
| 2 | Short warranty or unclear terms |
| 1 | Minimal warranty, unfavorable terms |
| 0 | No warranty or predatory terms |

### Credibility/Trust (10%)

| Score | Criteria |
|---|---|
| 5 | Grade A trust, strong evidence |
| 4 | Grade B trust, moderate evidence |
| 3 | Grade C trust, limited evidence |
| 2 | Grade D trust, insufficient evidence |
| 1 | Grade E warning signals |
| 0 | Confirmed fraud/scam |

### Payment Terms (5%)

| Score | Criteria |
|---|---|
| 5 | Favorable (net 30+, low/no advance) |
| 4 | Standard terms |
| 3 | Acceptable terms |
| 2 | Somewhat unfavorable (high advance) |
| 1 | Very unfavorable (100% advance, no credit) |
| 0 | Predatory terms |

## RECOMMENDATION LOGIC

```
1. Filter: Spec match ≥ 3 AND Trust ≥ C AND price within range
2. Score remaining on weighted dimensions
3. Rank by weighted total
4. If top two within 5% → prefer higher spec match / better terms
5. If price outlier → investigate before recommending
6. Recommend ONE primary + ONE alternate
7. State reasoning explicitly
```

**Never recommend on price alone.** Always consider spec match, credibility, terms.
