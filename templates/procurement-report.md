## SECTION-BY-SECTION GUIDANCE

### 01 Executive Summary

- **What was asked:** Restate the user's request in 1–2 sentences.
- **Headline finding:** The single most important number or conclusion.
- **Key recommendations:** Top 3 actionable items.
- **Confidence:** Overall assessment with brief justification.

Keep it under 200 words. This is what busy stakeholders read.

### 02 Project Specifications

- **Scope:** What's included, described precisely.
- **Assumptions:** Every assumption that affects the numbers.
- **Exclusions:** What's NOT included — prevents disputes.
- **Specifications:** Technical requirements, standards.

### 03 Detailed Cost Breakdown

The heart of the report. Use the format:

```
No | Description | Spec | Unit | Qty | Unit Price | Subtotal | Class/Source
```

Every line needs: quantity, unit, price, verification class, source.

Group by phase or category. Include subtotals per group.

### 04 Market Price Intelligence

For each significant item:

```
Item: [name]
Market Range: Rp X – Rp Y
Median: Rp Z
Recommended: [source]
Class: [verification class]
```

Show freshness and gaps.

### 05 Supplier Discovery

List top suppliers with:
- Type, location, trust grade
- Spec match, price evidence
- Key strengths/weaknesses

If <3 found, explain search methodology.

### 06 Price Comparison

Table format for key items:

```
| Item | Supplier A | Supplier B | Supplier C | Median | Recommended |
```

Analysis: spread, best value, savings opportunities.

### 07 Financial Recapitulation

Structured totals:

```
DIRECT:   Materials + Labor + Equipment + Subcontractors + Other
INDIRECT: Overhead + Admin + Contingency + Other
TAXES:    PPN + Other
GRAND TOTAL: Sum of all above
```

### 08 Optimization

Cost-saving opportunities with:
- What can be changed
- How much it saves
- What trade-off is involved

Alternative scenarios (base/optimized/premium).

### 09 Risks & Limitations

Honest assessment of:
- Price volatility
- Spec gaps
- Data limitations
- Confidence factors

### 10 Final Recommendation

Clear, actionable next steps:
- What to do
- Which supplier to choose
- What budget to approve

### 11 Source Register

Every source used, with:
- Item covered
- Source name/URL
- Price/value
- Date accessed
- Verification class
- Notes

## FILLING INSTRUCTIONS

1. **Start with executive summary** — forces clarity on key findings
2. **Complete specifications** — scope, assumptions, exclusions
3. **Build cost breakdown** — itemized, sourced, classified
4. **Add market intelligence** — price research per item
5. **Document suppliers** — who you found, their grades
6. **Compare prices** — show the analysis
7. **Recapitalize** — all totals, verify math
8. **Optimize** — find savings, present scenarios
9. **Assess risks** — be honest about limitations
10. **Recommend** — clear next steps
11. **Register sources** — complete audit trail

**Audit before presenting:** recalculate everything, verify sources, check confidence.
